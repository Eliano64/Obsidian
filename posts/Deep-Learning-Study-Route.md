# 深度学习在机器学习中的位置

深度学习是机器学习的一个分支。模型仍是参数化的函数，训练仍是定义损失、求梯度、沿负梯度更新参数。与线性模型的区别在函数形式：多层可微变换复合起来，特征表示与分类器一起从数据中学出。把深度学习当成一组框架 API 的集合，就看不到这条主线。

## 表示学习与特征工程的分工

传统机器学习里，特征通常由人设计，模型在这些特征上做分类或回归。深度学习把“从原始输入构造表示”这一步也纳入学习。以图像为例，靠前的层常对应边缘与局部纹理，中间的层组合出部件，靠后的层组合出物体。

这种从数据中学出的表示称为表示学习。表示学习并不总占优势：结构化表格数据上，人工特征配合中小规模模型往往更合适。优势出现在原始输入维度高、标注数据足够多、结构具有明显层次性的场景。

训练过程中仍有大量人工决策，包括数据清洗与增广、网络结构、损失函数、正则化强度。数据划分、结构、损失函数与正则化都属于训练前的人工配置，不会通过训练自动得到。

## 非线性与深度

仿射变换指形如 $Wx + b$ 的线性变换加平移。只把仿射层串联起来时，多层会合并成一次仿射变换：

$$
y = W_3(W_2(W_1x+b_1)+b_2)+b_3 = (W_3W_2W_1)x + (W_3W_2b_1+W_3b_2+b_3)
$$

堆叠得到的仍是一次仿射变换，不增加非线性表达能力，只让参数与计算更冗余。中间层宽度很小时，可表示的仿射映射还会进一步受限。初始化的尺度或归一化的缺失影响训练能否进行，这一结论仍然成立。

# 学习路线

学习顺序分为四步，顺序本身比速度重要。

1. 先掌握机器学习的基本概念：训练集与测试集、损失函数、过拟合、评价指标。
2. 再理解神经网络的训练流程：前向、损失、反向、更新如何组成一个循环。
3. 用到什么数学就补什么数学：矩阵形状对不上时补线性代数，看不懂导数连乘时补链式法则。
4. 用 PyTorch 把前面的内容落到代码上，完成一次训练循环并检查输出。

当下的工程实践会影响时间分配：样板代码已经可以借助工具生成，看懂代码、选择方法、分析训练结果因此比记住 API 更重要。

# 训练循环的七步

下面以“有标签、有可导损失、用反向传播求梯度、用优化器更新参数”的神经网络为例，这个循环可以拆成七步。

1. 定义模型结构：确定有几层、每层多少个单元、用什么激活函数。
2. 初始化参数：给权重一个初始值。
3. 前向传播：输入数据，逐层算到输出，得到预测。
4. 计算损失：用损失函数把预测与真实标签的差距变成一个数。
5. 反向传播：用链式法则算出损失对每个参数的梯度。
6. 更新参数：按负梯度方向执行一次参数更新，步长由学习率决定。学习率过小则收敛慢，过大则可能越过极小值来回震荡，具体分析见 [[Backpropagation-Chain-Rule]]。
7. 重复：回到第 3 步，直到达到停止条件。

第 2 步与第 6 步决定训练能否收敛。初始化尺度不当，信号会在层间放大到溢出或压缩到零；学习率不当，损失会震荡甚至发散。

下面这段代码是自包含的，可以直接运行。`Net()` 的构造过程完成了第 2 步，因为 `nn.Linear` 在创建时会按默认分布填充权重。

输入取 784 维，对应 28×28 图像展平后的像素数；第一层输出 128 维，第二层输出 10 维，对应 10 个类别。batch 取 64，表示一次送入 64 个样本。

```python
import torch
from torch import nn

class Net(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 128)   # 构造时即完成权重初始化
        self.fc2 = nn.Linear(128, 10)

    def forward(self, x):
        return self.fc2(torch.relu(self.fc1(x)))

model = Net()
loss_fn = nn.CrossEntropyLoss()          # 损失函数，接收 logits
opt = torch.optim.SGD(model.parameters(), lr=0.1)

x = torch.randn(64, 784)                 # 一个 batch 的假数据，784 维对应展平后的图像
y = torch.randint(0, 10, (64,))
for step in range(200):
    logits = model(x)                    # 3. 前向
    loss = loss_fn(logits, y)            # 4. 算损失
    opt.zero_grad()                      # 清空上一轮梯度
    loss.backward()                      # 5. 反向传播
    opt.step()                           # 6. 更新参数
```

`CrossEntropyLoss` 接收的 logits 是输出的原始类别分数，尚未归一化成概率。

`loss.backward()` 不需要指定“对哪些参数求导”，因为前向时框架记录了每个张量由哪个算子算出，反向时按记录逆序遍历计算图。这套机制叫自动微分，细节见 [[Backpropagation-Chain-Rule]]。

例子中的 `x` 与 `y` 由随机数生成，只用来演示循环能否完成一次迭代，不用于说明模型学到了什么。

> [!note] 按需查阅
>
> 不建议先把微积分、线性代数、概率论、数理统计从头学完再开始。脱离具体问题学数学，常见的结果是记住了公式却不知道这些公式解决什么问题。
>
> | 遇到的现象 | 需要补的内容 |
> | --- | --- |
> | 看不懂 $Wx + b$ 的形状怎么对上的 | 矩阵乘法、张量形状与广播 |
> | 不知道为什么要乘一个导数 | 一元链式法则、复合函数求导 |
> | 损失函数里的对数看不懂 | 对数运算、最大似然与交叉熵 |
> | 多个类别的输出怎么变成概率 | softmax、指数与归一化 |
> | 梯度消失、梯度爆炸是什么 | 导数的连乘、方差在层间的传播 |
> | 训练集好、测试集差 | 过拟合、正则化、偏差与方差 |
