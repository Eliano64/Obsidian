预测房价、预测温度这类任务回答的是“多少”。把一封邮件分成垃圾邮件与正常邮件、把一张影像分成恶性与良性、判断一个用户会不会点击广告，回答的却是“属于哪一类”。后一类任务的输出是有限集合里的离散标签，标签之间既没有大小也没有距离，用[[Linear-Regression|线性回归]]直接拟合，从输出范围到对异常值的敏感性都会出问题。

把类别编码成 0 和 1、直接套线性回归、再用 0.5 当分界，是最直接的想法。这个做法在两处失效：输出可以落在 0 到 1 之外，一个极端样本也能把整条分界线拉歪。

逻辑回归的改法只动输出端：保留线性部分，接sigmoid 函数，将任意实数映射到 $(0,1)$，让模型直接给出概率。

输出变成概率之后，损失函数、梯度形式与评估方式都跟着变：均方误差在概率输出上梯度性质差，常用做法是换成从最大似然推出的交叉熵；评估不能只看准确率；类别多于两个时 sigmoid 换成 softmax。

# 从回归到分类

## 分类任务

分类（Classification）指输出离散标签的任务：候选类别有限、互斥，每个样本恰好属于其中一个。类别数为 2 时叫二分类，多于 2 时叫多分类。

分类与回归的分界在输出的性质上，也在“错”的含义上。回归的输出是连续数值，可以相减，平方误差下差 2 比差 1 严重 4 倍，误差累加起来就是损失；分类的输出是标签，在普通的 0-1 错误率下，把猫判成狗和判成飞机计为同样的错，标签之间不存在距离。所以回归的损失可以建立在残差上，逻辑回归则用预测概率构造分类损失。模型一般也不直接输出类别，而是输出每个类别的概率，再按一条概率分界把概率转成类别。

## 直接套用线性回归

最直接的做法是把两类编码成 0 与 1，用 $z = \boldsymbol{w}^{\top}\boldsymbol{x}+b$ 拟合标签，再规定 $z > 0.5$ 判为正类。两条缺陷都出在这个规定上。

第一条是输出范围。线性回归的输出取遍 $(-\infty, +\infty)$，而概率的取值范围是 $[0,1]$，模型输出通常落在内部的 $(0,1)$。阈值之外的数值没有解释力：输出 10000 与输出 0.51 的两个样本都被判为正类，两个样本在“有多大概率是正类”上却分不出高低，损失函数也没有统一的量纲去衡量错得多严重。

第二条是异常值。线性回归用平方误差衡量偏差，离得越远罚得越重，一个尺寸特别大的样本足以把权重拉大，使分界线整体向该样本偏移；原本落在 0.5 正确一侧的普通样本被推过线，判错。出问题的不只是那一个点，而是一整片样本。

两条缺陷的根源相同：线性函数的值域与概率的值域不一致，误差的形状又与“判对判错”无关。要修的只是输出端。

# 用 sigmoid 把分数变成概率

## 函数形式

sigmoid 函数（也叫 logistic 函数）定义为：

$$\sigma(z) = \frac{1}{1+e^{-z}}$$

逻辑回归把线性部分的输出 $z = \boldsymbol{w}^{\top}\boldsymbol{x}+b$ 送入 sigmoid，作为对正类的预测概率：

$$\hat{y} = \sigma(\boldsymbol{w}^{\top}\boldsymbol{x}+b) = \frac{1}{1+e^{-(\boldsymbol{w}^{\top}\boldsymbol{x}+b)}}$$

前半段算一个分数，sigmoid 把分数换成概率。sigmoid 的性质都能从式子里读出来：因为 $e^{-z}>0$，分母恒大于 1，所以 $0<\sigma(z)<1$，取到的是开区间，在数学上不会精确等于 0 或 1。$z \to +\infty$ 时 $\sigma \to 1$，$z \to -\infty$ 时 $\sigma \to 0$，函数严格单调递增。另外， $\sigma(-z)=1-\sigma(z)$（两边通分到同一分母即可验证），所以图像关于点 $(0,0.5)$ 中心对称，$z$ 变号，概率随之变到 0.5 的另一侧。

## 概率解读与决策边界

$\hat{y}$ 读作“这个样本属于正类的概率”，即 $\hat{y} = P(y=1 \mid \boldsymbol{x})$。输出 0.8 表示模型认为该样本有八成把握是正类。这是 sigmoid 相对线性回归最关键的一点：给出的数本身带概率含义，而不只是一个用来排序的分数。判类需要一条概率分界，称为决策阈值，默认取 0.5。因为 $\sigma$ 严格递增且 $\sigma(0)=0.5$，条件 $\hat{y} \ge 0.5$ 与 $z \ge 0$ 完全等价：

$$\hat{y} \ge 0.5 \iff \frac{1}{1+e^{-z}} \ge \frac{1}{2} \iff 1+e^{-z} \le 2 \iff e^{-z} \le 1 \iff z \ge 0$$

> [!note] 阈值不是规定
> 于是**决策边界**是 $z = 0$，也就是 $\boldsymbol{w}^{\top}\boldsymbol{x}+b = 0$。这是一张超平面：线上的样本概率恰为 0.5，按 $z \ge 0$ 判为正类的约定归入正类一侧；两侧分别是预测为正类与负类的区域。sigmoid 自带这条边界，因为中点 0.5 恰好落在 $z$ 的零点上。这条边界是线性的，形状由特征决定。要划出弯曲的边界，得先做特征变换（见 [[Data-Preprocessing]]），或者换用[[Decision-Tree]]这类按单个特征取值逐层切分的模型。阈值取 0.5 只是习惯，不是规定，评估一节会看到移动阈值的后果。

## 阶跃函数的问题

硬阈值的理想形态是阶跃函数：$z<0$ 输出 0，$z \ge 0$ 输出 1，在 $z=0$ 处跳变。阶跃函数符合“只需要类别”的直觉，却不能用来训练：在 $z=0$ 处左右极限不等，函数不连续，导数不存在；在其余所有点上导数为 0。梯度下降靠导数判断参数该往哪边改、改多少，导数要么不存在、要么恒为零，参数得不到任何方向信息，更新无法进行。导数为零还意味着 $z$ 从 0.1 变到 100 对损失毫无影响，模型区分不出“差一点”和“差很远”，而这正是训练最需要的信息。

sigmoid 是阶跃函数的平滑版本：处处连续可导，在 $z=0$ 附近最陡，两端渐近平坦。中段的陡峭保住了“靠近边界时敏感”的性质，整体的平滑让梯度在每一点都有定义。

## 导数的简洁形式

把分母写成幂，用链式法则求导：

$$\sigma(z) = \left(1+e^{-z}\right)^{-1} \quad\Longrightarrow\quad \sigma'(z) = -(1+e^{-z})^{-2}\cdot\left(-e^{-z}\right) = \frac{e^{-z}}{\left(1+e^{-z}\right)^{2}}$$

再把结果拆成两个因子的乘积：

$$\frac{e^{-z}}{\left(1+e^{-z}\right)^{2}} = \frac{1}{1+e^{-z}}\cdot\frac{e^{-z}}{1+e^{-z}} = \sigma(z)\left(1-\sigma(z)\right)$$

最后一处用到 $1-\sigma(z) = e^{-z}/(1+e^{-z})$。这个形式的用处在于只依赖 $\sigma(z)$ 本身：前向计算已经把 $\hat{y}$ 算出来了，反向传播时导数就是一次乘法 $\hat{y}(1-\hat{y})$，不必重新碰指数。$\hat{y}(1-\hat{y})$ 是一条开口向下的抛物线，在 $\hat{y}=0.5$ 处取最大值 0.25，在两端趋近 0，这个“两端趋零”的性质在下一节会变成麻烦。

# 损失函数的选择

## 均方误差与 sigmoid 的组合

均方误差（MSE）取预测与标签之差的平方，单个样本写作：

$$L = \frac{1}{2}\left(\hat{y} - y\right)^{2}$$

系数 $\frac{1}{2}$ 只是为了让求导时平方产生的 2 被消掉。把平方误差接在 sigmoid 后面，凸性与梯度各出一处问题。

第一处是凸性。线性回归配 MSE 时，损失是参数的凸二次函数；设计矩阵列满秩时，全局最优解唯一。采用合适步长，梯度下降可以收敛到最优解。平方误差与 sigmoid 复合后，损失一般不再是凸函数，可能出现多个局部极小，迭代结果也可能受初值影响。

第二处是梯度。设 $\hat{y} = \sigma(z)$，$L$ 对 $z$ 的导数由两段乘起来：

$$\frac{\partial L}{\partial \hat{y}} = \hat{y} - y, \qquad \frac{\partial \hat{y}}{\partial z} = \sigma'(z) = \hat{y}\left(1-\hat{y}\right)$$

按链式法则把两段相乘：

$$\frac{\partial L}{\partial z} = \frac{\partial L}{\partial \hat{y}}\cdot\frac{\partial \hat{y}}{\partial z} = \left(\hat{y} - y\right)\hat{y}\left(1-\hat{y}\right)$$

两个因子在极端处反着走。正样本 $y=1$ 被错得离谱时 $\hat{y} \approx 0$，第一个因子 $\hat{y}-y = -1$，量级接近上限；第二个因子 $\hat{y}(1-\hat{y}) \approx 0$，因为 sigmoid 在 0 端早就压平了。乘积约为 0：

$$\frac{\partial L}{\partial z} = \underbrace{\left(\hat{y} - y\right)}_{=-1}\cdot\underbrace{\hat{y}\left(1-\hat{y}\right)}_{\approx 0} \approx 0$$

预测概率接近错误类别的极端值时，梯度反而接近零，参数更新因而缓慢。这就是梯度消失在这套组合里的具体形态：损失的数值很大，传回参数的信号却接近零。MSE 在这里的问题是幅度：在最需要纠正的样本上给出最弱的信号。

## 分类损失应满足的条件

对二分类，模型的输出是一个概率 $p = \hat{y}$。合理的分类损失至少应当满足三条要求。

- 真实标签 $y=1$ 时，$p$ 越接近 1 损失越小，$p$ 接近 0 时惩罚要大；
- 真实标签 $y=0$ 时对称，$p$ 越接近 0 损失越小，$p$ 接近 1 时惩罚要大；
- 惩罚的峰值出现在模型非常自信却判错的位置。

第三条容易被读错。$p=0.5$ 是模型最不确定的点，损失并不在这里最大：两种结果都可能，此时惩罚应当居中。真正的最大损失在真实标签 $y=1$ 而模型给出 $p \approx 0$ 处：模型非常确信，而且确信的方向与标签相反。MSE 的惩罚有上界，梯度也不会随纠错需求增大：MSE 的惩罚只随 $|\hat{y}-y|$ 增长，看似合理，但上一节已经算出，正在“自信判错”的位置上 MSE 的梯度趋近 0，惩罚再大也传不回参数。

要写出满足这三条的函数，需要三件工具：对数函数、伯努利分布，以及概率与似然的区分。

## 对数函数

引入对数有两个理由。一是单调性：$\log$ 严格递增，最大化一个正数等价于最大化该数的对数，使概率取最大值的参数不会因为取对数而改变。二是数值稳定性：$m$ 个样本的联合概率是 $m$ 个小于 1 的数连乘，样本一多结果就下溢成 0，计算机无法表示，取对数把连乘换成连加：

$$\log(a\cdot b) = \log a + \log b$$

下溢消失，求导也不必再展开 $m$ 项乘积法则，逐项相加即可。而 $-\log x$ 在 $(0,1)$ 上的形状还正好满足上一节的要求：$x \to 1$ 时 $-\log x \to 0$，$x \to 0$ 时 $-\log x \to +\infty$，概率越接近正确答案惩罚越接近 0，越接近错误答案惩罚涨得越快。

## 伯努利分布

二分类的标签是一次只有两种结果的随机试验，像抛一枚不一定均匀的硬币：结果为 1 的概率是 $p$，结果为 0 的概率是 $1-p$。两种情形可以用一个式子统一写出来：

$$P(y=1) = p, \quad P(y=0) = 1-p \quad\Longrightarrow\quad P(y) = p^{y}\left(1-p\right)^{1-y}$$

$y=1$ 时第二项的指数为 0，$(1-p)^{0}=1$，只剩 $p$；$y=0$ 时第一项为 1，只剩 $1-p$。逻辑回归给出的 $\hat{y}$ 正是样本属于正类的概率 $p$，代入后得到单个样本被预测正确的概率：

$$P(y \mid \boldsymbol{x}) = \hat{y}^{y}\left(1-\hat{y}\right)^{1-y}$$

## 概率与似然

同一个表达式 $P(\text{数据} \mid \text{参数})$，从两个方向读，就是两个概念。概率是参数已知、数据未知时，预测数据出现的可能性。假设硬币均匀，即正面概率 $p=0.5$，问抛 10 次恰好出现 7 次正面的概率是多少，这是概率。

似然是数据已知、参数未知时，评估参数是否合理。已经抛了 10 次，观测到 7 次正面与 3 次反面，问 $p$ 取多少最符合这个观测，这是似然。两者的算式相同，区别在固定谁、变动谁：概率固定参数、变动数据，似然固定数据、变动参数。训练时数据是给定的，要变的是参数，所以这里起作用的是似然。

## 从最大似然到交叉熵

最大似然估计（MLE）的出发点是：这批数据已经出现了，那么让这批数据出现概率最大的参数，就是最好的参数。

$m$ 个样本相互独立，联合概率是各自概率的连乘，这个乘积就是似然函数，其中 $\hat{y}_i$ 由参数 $\boldsymbol{\theta} = (\boldsymbol{w}, b)$ 决定：

$$L(\boldsymbol{\theta}) = \prod_{i=1}^{m}\hat{y}_i^{y_i}\left(1-\hat{y}_i\right)^{1-y_i}$$

直接对乘积求导要展开 $m$ 项乘积法则，样本稍多还会下溢，因此取对数。对数严格递增，不改变最大值的位置，同时把连乘变成连加，结果叫对数似然（log-likelihood），也就是似然取对数：

$$\log L(\boldsymbol{\theta}) = \sum_{i=1}^{m}\left[y_i\log\hat{y}_i + \left(1-y_i\right)\log\left(1-\hat{y}_i\right)\right]$$

统计学要让似然最大，机器学习要把损失降到最小，于是加负号把最大化翻成最小化，再除以样本数 $m$，让损失的数值不随批量大小变化：

$$J(\boldsymbol{\theta}) = -\frac{1}{m}\sum_{i=1}^{m}\left[y_i\log\hat{y}_i + \left(1-y_i\right)\log\left(1-\hat{y}_i\right)\right]$$

这就是交叉熵损失（Cross-Entropy Loss），二分类下的形式也叫二元交叉熵（BCE）。交叉熵在这里的定义是：衡量模型给出的预测分布与真实标签分布之间差距的损失，差距越小，损失越小。交叉熵由最大似然推出，所以最小化交叉熵与最大化数据出现的概率是同一件事。把 sigmoid 代进去之后，$J$ 关于参数是凸函数；严格凸与有限最优需要额外条件，特征完全可分时最优参数可能不存在有限解。

$y_i$ 只能取 0 或 1，求和里永远只有一项在起作用，这一项就是前面三条要求本身：判对时惩罚消失，判错且自信时惩罚发散。

| 真实标签 | 起作用的损失项 | 这一项的行为 |
| --- | --- | --- |
| $y_i = 1$ | $-\log\hat{y}_i$ | $\hat{y}_i$ 接近 1 时损失趋于 0，接近 0 时损失趋于 $+\infty$ |
| $y_i = 0$ | $-\log\left(1-\hat{y}_i\right)$ | $\hat{y}_i$ 接近 0 时损失趋于 0，接近 1 时损失趋于 $+\infty$ |

## 交叉熵的信息论解释

熵（Entropy）度量一个分布的不确定性，也就是想弄清这件事的结果、平均需要多少信息量。公平硬币正反各半，完全猜不中，熵最大。一枚 99% 出正面的硬币几乎没有悬念，熵很小。确定事件（100% 出正面）的熵为 0。交叉熵则度量两个分布的差距。分类任务里的两个分布是模型的预测概率分布与真实标签分布，后者是只有正确类别为 1 的 one-hot 分布。交叉熵算的是用预测分布去描述真实标签分布时还差多少，差得越少，模型越可靠。单个样本上的读数就是 $-\log p(\text{正确类别})$：模型给正确类别的概率越高，这个代价越接近 0。把正确类别的概率压到接近 0，代价发散。信息论的解释与最大似然的推导落在同一个式子上：交叉熵是“用预测分布去描述真实标签分布”这个动作本身的价格，而不是人为设定的惩罚。

# 梯度

单个样本的交叉熵记作 $J_i = -\left[y\log\hat{y} + (1-y)\log(1-\hat{y})\right]$，其中 $\hat{y} = \sigma(z)$，$z = \boldsymbol{w}^{\top}\boldsymbol{x}+b$。求 $J_i$ 对 $z$ 的导数分两步。

第一步，对 $\hat{y}$ 求导。先通分，再把分子展开为 $y - y\hat{y} - \hat{y} + y\hat{y} = y - \hat{y}$，最后取负号：

$$\begin{aligned}
\frac{\partial J_i}{\partial \hat{y}} &= -\left(\frac{y}{\hat{y}} - \frac{1-y}{1-\hat{y}}\right) \\
&= -\frac{y\left(1-\hat{y}\right) - \left(1-y\right)\hat{y}}{\hat{y}\left(1-\hat{y}\right)} \\
&= \frac{\hat{y} - y}{\hat{y}\left(1-\hat{y}\right)}
\end{aligned}$$

第二步，乘上 sigmoid 的导数。第一步得到的分母 $\hat{y}(1-\hat{y})$ 恰好是 $\sigma'(z)$，被乘除了：

$$\begin{aligned}
\frac{\partial J_i}{\partial z} &= \frac{\partial J_i}{\partial \hat{y}}\cdot\frac{\partial \hat{y}}{\partial z} \\
&= \frac{\hat{y} - y}{\hat{y}\left(1-\hat{y}\right)}\cdot\hat{y}\left(1-\hat{y}\right) \\
&= \hat{y} - y
\end{aligned}$$

这个相消不是巧合：交叉熵对 $\hat{y}$ 的导数分母是 $\hat{y}(1-\hat{y})$，而 sigmoid 对 $z$ 的导数正好是 $\hat{y}(1-\hat{y})$，两者互为倒数。

再往前一步到参数。$z$ 对第 $j$ 个权重与对偏置的偏导分别是 $\partial z/\partial w_j = x_j$、$\partial z/\partial b = 1$，所以单个样本的偏导是：

$$\frac{\partial J_i}{\partial w_j} = \left(\hat{y} - y\right)x_j, \qquad \frac{\partial J_i}{\partial b} = \hat{y} - y$$

$m$ 个样本取平均，得到要放进更新式的两个梯度：

$$\frac{\partial J}{\partial w_j} = \frac{1}{m}\sum_{i=1}^{m}\left(\hat{y}_i - y_i\right)x_{i,j}, \qquad \frac{\partial J}{\partial b} = \frac{1}{m}\sum_{i=1}^{m}\left(\hat{y}_i - y_i\right)$$

这两个式子恰好是线性回归 MSE 的梯度去掉一个常数因子 2 之后的样子：

| 量 | 线性回归（MSE） | 逻辑回归（交叉熵） |
| --- | --- | --- |
| 权重梯度 | $\frac{2}{m}\sum_i\left(\hat{y}_i - y_i\right)x_{i,j}$ | $\frac{1}{m}\sum_i\left(\hat{y}_i - y_i\right)x_{i,j}$ |
| 偏置梯度 | $\frac{2}{m}\sum_i\left(\hat{y}_i - y_i\right)$ | $\frac{1}{m}\sum_i\left(\hat{y}_i - y_i\right)$ |
| $\hat{y}$ 的含义 | $\boldsymbol{w}^{\top}\boldsymbol{x}_i + b$ | $\sigma\left(\boldsymbol{w}^{\top}\boldsymbol{x}_i + b\right)$ |

更新式的形式与线性回归相同，区别在 $\hat{y}$ 是经过 sigmoid 的概率，而不是线性输出。

# 分类任务的评估

## 混淆矩阵

准确率是判对的样本占全部样本的比例。类别比例悬殊时准确率几乎没有信息量：正类只占极少数时，把全部样本都判为负类也能得到很高的准确率，而正类一个都没有被识别出来。

混淆矩阵（Confusion Matrix）把所有样本按真实类别与预测类别交叉计数，排成一张表，是分类评估的基础。计数之前要先定下哪一类算正类。本节把“恶性”取为正类，热图上的 0 与 1 只是类别编码，不用作正负类的标记。

|  | 预测为恶性（正类） | 预测为良性（负类） |
| --- | --- | --- |
| 实际为恶性（正类） | TP 41 | FN 1 |
| 实际为良性（负类） | FP 1 | TN 71 |

四个格子的名字由“真实类别”与“判得对不对”两件事组合而成。TP（True Positive，真正例）是正类被判成正类。FN（False Negative，假负例）是正类被判成负类，也就是漏报。FP（False Positive，假正例）是负类被判成正类，也就是误报。TN（True Negative，真负例）是负类被判成负类。这张表一共 114 个样本，即 41 + 1 + 1 + 71。

两类错误的代价通常不对等。肿瘤筛查里，FN 把恶性判成良性，患者会错过治疗；FP 把良性判成恶性，代价是多做一次复查。指标的选择由这个不对称决定：这里应当优先压低 FN。准确率把两类错误算成同一个数，正好丢掉了这个不对称。

## 精确率、召回率与 F1

从混淆矩阵出发，把关注点放在正类上，得到两个比例：

$$\text{Precision} = \frac{TP}{TP+FP}, \qquad \text{Recall} = \frac{TP}{TP+FN}$$

精确率（Precision）的分母是模型判为正类的全部样本，衡量判为正类的样本中真实正类的比例，即预测质量。召回率（Recall）的分母是真实正类的全部样本，问的是“真正的正类被抓到了多少”，衡量覆盖能力。两个分母不同，一个从预测出发，一个从真实出发，所以同一张矩阵能给出两个比例，各自回答一个问题。F1 把两者合成一个数，取的是调和平均（两项取倒数后求平均，再取一次倒数）：

$$F1 = 2\cdot\frac{P\times R}{P+R}$$

调和平均由较小的一项主导：精确率与召回率只要有一个低，F1 就低；算术平均则会被较大的一项抬高。所以两者都高时 F1 才高，单看一个数就会漏掉另一面的短板。

两者此消彼长，移动决策阈值就能看到。把阈值从 0.5 调低，更多样本越过线被判为正类：原本漏掉的正类重新被判对，召回率上升，同时被误判的负类增多，精确率下降。调高阈值则相反。在乳腺癌场景里宁可误报也不能漏报，阈值应当取低，让召回率优先，接受精确率的损失。

## ROC 曲线与 AUC

精确率与召回率都是在一个固定阈值上算出来的，换阈值就换一组数，ROC 曲线把阈值的影响整个画出来。ROC 曲线（Receiver Operating Characteristic Curve）以假正率 FPR 为横轴、真正率 TPR 为纵轴。把决策阈值从最严扫到最松，每个阈值在图上落一个点，连起来就是这条曲线。两个坐标的定义是：

$$\text{FPR} = \frac{FP}{FP+TN}, \qquad \text{TPR} = \frac{TP}{TP+FN}$$

FPR 是负类中被误判为正类的比例，TPR 与召回率是同一个量，即正类被正确识别的比例。阈值很高时几乎没有样本被判为正类，两个比率都接近 0，点落在左下角；阈值放到最低，全部样本判为正类，两个比率都到 1，点落在右上角。示例数据里的 ROC 例子 AUC 为 0.9954，曲线从原点几乎垂直升到 TPR 接近 1，再水平向右；阈值取 0.8 时 TPR 已到 0.81，FPR 只有 0.02。

AUC（Area Under Curve）是 ROC 曲线下的面积，取值 0 到 1。对角线对应随机猜测，AUC 为 0.5；AUC 越接近 1，模型把正类排在负类之前的能力越强。AUC 的关键性质是与阈值无关：一条曲线由所有阈值上的点组成，AUC 汇总的是整条曲线的高度，不依赖某个具体阈值，因此可以直接用来比较不同模型，不必先对齐各自的阈值。

# 多分类与神经网络

## softmax 把得分变成概率分布

二分类只有一个分数，sigmoid 把分数折成概率就够了。类别变成 $K$ 个（猫、狗、猪）时，需要的是 $K$ 个互相关联的概率。先给每个类别算一个独立得分：

$$z_k = \boldsymbol{w}_k^{\top}\boldsymbol{x} + b_k, \qquad k = 1,\dots,K$$

这些未归一化的得分叫 logits，可以取任意实数，正负不限，加起来也不等于 1，不能直接当概率。softmax 把得分换成概率分布：

$$\hat{y}_k = \frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}$$

分子恒正，所以每一项都大于 0；各项分子之和恰好是分母，所以总和严格为 1；指数把得分之间的差放大，得分高的一项占的份额更大。三类的一个具体例子：$z = [2.0, 1.0, 0.1]$，三个指数约为 $7.39$、$2.72$、$1.11$，总和约 $11.2$，得到 $\hat{y} = [0.66, 0.24, 0.10]$。分类结果取概率最大的那一类，这里没有单一的阈值，类别之间是竞争关系：一类的概率升上去，其他类必然降下来。

## 多分类交叉熵

标签是一个 one-hot 向量，正确类别的位置为 1，其余为 0，交叉熵对 $K$ 个类别求和：

$$L = -\sum_{k=1}^{K}y_k\log\hat{y}_k$$

承接上面的例子，真实类别是第 0 类，$y = [1, 0, 0]$，代入后只有一项非零：

$$L = -\left(1\cdot\log 0.66 + 0\cdot\log 0.24 + 0\cdot\log 0.10\right) = -\log 0.66 \approx 0.42$$

与二分类的情形相同，多分类交叉熵实质就是 $-\log\hat{y}_{\text{正确类}}$：正确类别的概率越接近 1，损失越接近 0；把正确类概率压到接近 0，损失发散。

## 多分类的梯度

对 softmax 的输出求导，先要对自身得分与其他得分分别求偏导。记 $S = \sum_j e^{z_j}$，则 $\hat{y}_k = e^{z_k}/S$。对自身得分，分子与分母都含 $e^{z_k}$，用商的求导法则：

$$\frac{\partial \hat{y}_k}{\partial z_k} = \frac{e^{z_k}S - e^{z_k}\cdot e^{z_k}}{S^{2}} = \frac{e^{z_k}}{S} - \left(\frac{e^{z_k}}{S}\right)^{2} = \hat{y}_k\left(1 - \hat{y}_k\right)$$

对其他得分（$j \ne k$），分子与 $z_j$ 无关，只有分母随之变化：

$$\frac{\partial \hat{y}_k}{\partial z_j} = \frac{0\cdot S - e^{z_k}\cdot e^{z_j}}{S^{2}} = -\hat{y}_k\hat{y}_j$$

再对 $L = -\log\hat{y}_k$（$k$ 是正确类别）用链式法则，正确类别对应的那一项是：

$$\frac{\partial L}{\partial z_k} = -\frac{1}{\hat{y}_k}\cdot\hat{y}_k\left(1-\hat{y}_k\right) = -\left(1-\hat{y}_k\right) = \hat{y}_k - 1$$

其他类别那一项是：

$$\frac{\partial L}{\partial z_j} = -\frac{1}{\hat{y}_k}\cdot\left(-\hat{y}_k\hat{y}_j\right) = \hat{y}_j$$

因为正确类别的 $y_k=1$、其余 $y_j=0$，两式可以合成一条：

$$\frac{\partial L}{\partial z_k} = \hat{y}_k - y_k$$

softmax 的导数里带着 $\hat{y}_k$，交叉熵对 $\hat{y}_k$ 求导又给出 $1/\hat{y}_k$，两者相乘后约掉，梯度里只剩“预测减标签”，与二分类的 $\hat{y}-y$ 是同一个形状。

## 逻辑回归作为单层神经网络

把逻辑回归的四个部分按层摆开：输入是特征 $x_1, x_2, \dots$，一层连接把输入乘权重、加偏置得到 $z$，激活函数是 sigmoid（多分类时是 softmax），输出是概率。这就是一个没有隐藏层的单层神经网络，“逻辑回归”与“单层神经网络”的差别只在叫法，参数、前向计算与梯度完全对应。这也解释了为什么现代网络的输出层在单标签分类中普遍采用这一套：最后一层是线性变换加 softmax，损失是交叉熵。逻辑回归是这套结构里最简单的情形，把这一结构讲清楚，也就讲清了深度网络输出层在做什么。各类模型的分工见 [[Machine-Learning-Overview]]。

## `nn.Softmax` 与 `CrossEntropyLoss` 叠加

PyTorch 里很容易写出下面这段：

```python
model = nn.Sequential(
    ...,
    nn.Linear(128, 10),        # 输出 10 个类别的得分
    nn.Softmax(dim=-1),        # 提前把得分变成概率，与下面的损失重复
)
criterion = nn.CrossEntropyLoss()   # 内部自带 softmax，期望未归一化的 logits
```

训练时的表现是 loss 缓慢下降，准确率可能长期停留在接近随机的水平，具体取决于初始化与优化设置。原因是 CrossEntropyLoss 期望的输入是未归一化的 logits。CrossEntropyLoss 内部先做 log_softmax 再取负对数，把“softmax 转概率”与“交叉熵”合成一步算完。网络末尾再接一个 nn.Softmax，等于对概率又做了一次 softmax：第一次已经把 logits 压进 $(0,1)$ 且和为 1，各类之间的差距缩小。第二次 softmax 进一步压缩类别概率的差异，并改变梯度，可能妨碍训练。

训练时移除模型末尾的 softmax，直接向损失函数传入 logits：

```python
model = nn.Sequential(
    ...,
    nn.Linear(128, 10),        # 只留未归一化的 logits
)
criterion = nn.CrossEntropyLoss()
```

> [!warning] CrossEntropyLoss 的输入
> 改掉之后 loss 通常会下降，幅度取决于初始化与优化设置。损失函数与其配套的激活需要成对使用，两者组合才构成一个完整的输出层；PyTorch 把这些配对打包进一个函数，代价是调用方必须知道输入是概率还是得分。合并计算还顺带解决了数值问题：分开算时 softmax 可能输出 0，再取对数得到负无穷；log_softmax 用 log-sum-exp 的形式绕开这一步。因此，训练时由 CrossEntropyLoss 完成这一步转换。
