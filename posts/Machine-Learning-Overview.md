# 人工智能与机器学习

- **人工智能（AI）**：研究如何让计算机完成感知、推理与决策任务，既包含人工规则系统，也包含数据驱动模型。
- **机器学习（ML）**：从数据中自动拟合参数或规则以完成预测与决策。
- **深度学习（DL）**：机器学习的子集，利用多层神经网络直接从像素、波形或文本中逐层学习特征表示。
- **大语言模型（LLM）**：主流基于 Transformer 架构的超大规模神经网络，通过预测上下文中的下一词元习得通用语言与推理能力。

# 数据、特征与标签

**样本**是一次独立观测记录，**特征**是描述样本的输入属性，监督任务中待预测目标称为**标签**（如预测房价时，单套房源为一条样本，面积与房龄为特征，成交价为标签）。

标准二维表格与张量表示中，**行数就是样本数，列数就是特征数（输入维度）**；去重或删除异常样本改变行数，独热编码或特征工程改变列数而保持行数不变。传统机器学习通常先靠人工筛选与构造特征列（如 [[Data-Preprocessing]]），深度学习则直接由网络自动组合高层特征表示。

# 模型、参数与学习算法

同一个模型形式可配不同学习算法（如线性回归既可用解析解也可用梯度下降）；最终效果不仅取决于算法，更依赖数据划分与目标函数设计。四项核心概念的职责划分如下：

| 概念 | 核心职责 | 典型例子 |
| --- | --- | --- |
| **模型（Model）** | 选定函数结构及待求参数集合 | 线性加权函数、决策树划分规则、神经网络拓扑 |
| **参数（Parameter）** | 训练过程自动拟合得到的内部数值 | 线性回归权重与偏置、树分裂阈值 |
| **超参数（Hyperparameter）** | 训练前人工设定、在验证集筛选的配置 | 学习率、正则系数、树最大深度 |
| **学习算法（Algorithm）** | 在训练数据上搜索参数的具体方法 | 正规方程、[[Gradient-Descent|梯度下降]]、不纯度贪心分裂 |

# 学习设置

根据监督信号与交互反馈形态，机器学习主要分为三类范式：

| 范式 | 训练输入构成 | 核心目标 | 典型代表 |
| --- | --- | --- | --- |
| **监督学习** | 特征 + 对应标签 | 学习输入到输出的条件映射 | 回归（连续值）、分类（离散类） |
| **无监督学习** | 仅无标签特征 | 发现样本分组或低维压缩结构 | 聚类（K-Means）、降维（PCA，见 [[Unsupervised-Learning]]） |
| **强化学习** | 环境状态 + 动作 + 延迟奖励 | 学习最大化长期累计奖励的策略 | 游戏博弈、机器人导航控制 |

## 监督学习

> [!note] 自监督学习的监督来源
> 大语言模型无需人工逐条打标签，直接利用文本天然次序以「上下文预测下一词元」作为内部监督信号（自监督），因此能吸收海量无标注语料。

完整监督学习工程闭环分为四步：

1. **定义任务与指标**：依据连续/离散目标选定匹配业务代价的评估指标。
2. **互斥数据划分**：分出训练集（拟合参数与预处理统计量）、验证集（挑超参数与模型）、测试集（最后只评估一次泛化表现，严禁数据泄露，见 [[Data-Preprocessing]]）。
3. **训练与诊断**：同时监控训练误差与验证误差，区分**欠拟合**（容量不足、双误差均高）与**过拟合**（记忆噪声、验证误差反升，见 [[Model-Evaluation]]）。
4. **上线与重训**：部署后监控线上分布漂移并按需周期更新。

## 无监督学习

在没有标签时从特征矩阵内部结构提取规律：聚类按相似度将样本划分互斥群组（簇含义须事后结合业务解释），降维把高维冗余坐标压缩到低维主子空间，具体原理与推导见 [[Unsupervised-Learning]]。

## 强化学习

智能体在环境中观测状态并执行动作，依据环境返回的延迟且稀疏的奖励信号不断修正策略；仅靠离线静态日志训练时，未覆盖状态动作区的策略表现无法直接保证。
