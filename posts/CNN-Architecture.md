# 分类网络的整体结构

图像分类网络分两段：特征提取器重复“卷积、激活、池化”，让通道变多、空间变小；分类器把特征图展平，经全连接层输出各类得分。

以 CIFAR-10 的一个分类网络为例。输入 3×32×32，10 类。卷积核 3×3、四周补一圈零（padding=1）、步幅 1；池化用 2×2 窗口、步幅 2，每个阶段的空间尺寸减半。参数量含偏置：

| 阶段 | 操作 | 输出形状 | 参数量 |
| --- | --- | --- | --- |
| 输入 | 3×32×32 | 3×32×32 | 0 |
| 1 | Conv 3×3，16 通道 → ReLU → MaxPool 2×2 | 16×16×16 | 448 |
| 2 | Conv 3×3，32 通道 → ReLU → MaxPool 2×2 | 32×8×8 | 4,640 |
| 3 | Conv 3×3，64 通道 → ReLU → MaxPool 2×2 | 64×4×4 | 18,496 |
| 4 | Conv 3×3，64 通道 → ReLU → MaxPool 2×2 | 64×2×2 | 36,928 |
| 展平 | 64×2×2 → 256 | 256 | 0 |
| 全连接 | 256 → 128 → ReLU | 128 | 32,896 |
| 输出 | 128 → 10 | 10 | 1,290 |

总参数量为 94,698，其中两个全连接层占 34,186。池化后保留 64×2×2 个特征，分类头只需接收 256 维输入。

整套前向可以写成：

```python
import torch
from torch import nn

# 四个 Conv-ReLU-MaxPool 块，通道 3 → 16 → 32 → 64 → 64
channels = [3, 16, 32, 64, 64]
blocks = []
for cin, cout in zip(channels[:-1], channels[1:]):
    blocks += [
        nn.Conv2d(cin, cout, 3, padding=1),  # 3×3 卷积，空间尺寸不变
        nn.ReLU(),
        nn.MaxPool2d(2),                     # 空间尺寸减半
    ]

model = nn.Sequential(
    *blocks,
    nn.Flatten(),                            # 64×2×2 -> 256
    nn.Linear(64 * 2 * 2, 128),
    nn.ReLU(),
    nn.Linear(128, 10),                      # 10 个 logits，不接激活
)
print(model(torch.zeros(1, 3, 32, 32)).shape)  # torch.Size([1, 10])
```

换通道数或块数，形状与参数量都会变。输入换成 224×224 时，卷积层参数不变，展平后的长度变长，分类头输入维度需要重设。

# 特征提取

## 卷积层

一个卷积核的形状是 $C_{in}\times k\times k$，在通道方向覆盖全部输入，把各通道乘积相加得到一个响应。`Conv2d(3, 16, 3, padding=1)` 用 16 个 3×3×3 的核，把 3×32×32 变成 16×32×32。

### 输出尺寸

输入边长 $n$、核边长 $k$、每侧补零 $p$、步幅 $s$ 时，输出边长按下面的公式计算：

$$
n_{out}=\left\lfloor\frac{n+2p-k}{s}\right\rfloor+1
$$

本网络的卷积用 $k=3$、$p=1$、$s=1$，输出与输入同尺寸；池化用 $k=2$、$p=0$、$s=2$，空间减半。补零让边缘位置也能取到完整的 $k\times k$ 窗口，步幅决定窗口每隔几格移动一次；两者共同决定输出边长。

### 参数量

含偏置的卷积参数为：

$$
C_{out}\times(C_{in}\times k\times k)+C_{out}
$$

第一项是权重：每个输出通道对全部输入通道各有一份 $k\times k$。第二项是偏置：每个输出通道一个。3 通道、16 个 3×3 核是 $16\times(3\times3\times3)+16=448$。改变输入高宽不改变这一层的参数；展平后分类头的输入维度需要随之调整。

## 激活

卷积带偏置是仿射运算：固定核时，输出是输入的线性组合再加常数。只堆叠卷积不加非线性，整个网络仍是仿射映射，无法表达变量之间的非线性关系。

ReLU 逐元素取 $\max(0,x)$，负值置零、正值保留。加入这一层之后，后续卷积才能组合出复杂模式。

## 池化与感受野

最大池化在小窗口内取最大值，没有可学习参数，输出尺寸同样按上面的公式计算：

![[../assets/cnn-maxpool-4x4.svg]]

池化降低分辨率与计算量，让后续层的一个核对应原图更大的区域。代价是位置精度下降。

感受野与采样间隔逐层更新：

$$
r_{out}=r_{in}+(k-1)\times j_{in},\qquad j_{out}=j_{in}\times s
$$

$r$ 是感受野边长，$j$ 是相邻输出位置在输入上的间隔。conv 3×3、$s=1$ 时 $r$ 从 1 变 3，$j$ 保持 1；pool 2×2、$s=2$ 时 $r$ 变 4、$j$ 变 2；再一层 3×3 卷积，$r$ 变 8。池化把采样间隔翻倍，第三层的 3×3 核因此覆盖 8×8 的输入区域。

# 分类头

最后一层输出 64×2×2，展平为 256 维，经 256→128→10 得到 10 个 logits。logits 是未归一化的得分，可以取任意实数，经 softmax 变成概率：

$$
p_i=\frac{\exp(z_i)}{\sum_j \exp(z_j)}
$$

$z_i$ 是第 $i$ 类的得分，概率 $p_i$ 非负且和为 1；$z=(2,1,0)$ 时概率约 $(0.665,0.245,0.090)$。

> [!note] 损失与 logits
> 训练时用真实类别的概率 $p_y$ 计算交叉熵 $-\ln(p_y)$：$p_y$ 越大，损失越小。PyTorch 的 `CrossEntropyLoss` 直接接收 logits，并在内部完成 log\_softmax 与负对数。

分类头用全连接仍然合理：输入是 256 维高层特征，不是原始像素，全连接在这里负责组合特征并输出得分。
