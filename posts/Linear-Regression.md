# 线性回归的位置

监督学习里，标签是连续数值时（房价、温度、销量），任务要回答的是“给定这些特征，输出是多少”，这一类任务称为回归，整个监督学习的版图见 [[Machine-Learning-Overview]]。线性回归（Linear Regression）是最简单的一种做法：把输出写成特征的加权和。特征是描述一个样本的各个属性，例如面积与房龄。名字里有两件事值得拆开：“线性”规定模型的形式，“回归”交代任务的类型。

线性回归先是一个模型，其次才是一套训练方法。下文只处理前一半：模型的形式怎么定，好坏怎么量，参数怎么解出来。把损失逐步降下去的过程见 [[Gradient-Descent]]。

# 什么算线性

数学上的线性描述按比例变化、可叠加的关系。一个映射 $f$ 满足两条性质就称为线性：输入放大 $a$ 倍，输出也放大 $a$ 倍，即 $f(a\boldsymbol{x}) = a f(\boldsymbol{x})$，这条叫齐次性；两个输入叠加后的输出等于各自输出之和，即 $f(\boldsymbol{x} + \boldsymbol{z}) = f(\boldsymbol{x}) + f(\boldsymbol{z})$，这条叫可加性。

两条性质合起来说明：输入的任何线性组合送进 $f$，输出是各自输出的同一组合，即 $f(a\boldsymbol{x} + c\boldsymbol{z}) = a f(\boldsymbol{x}) + c f(\boldsymbol{z})$。加权求和满足这一点：逐个特征的乘法是齐次的，各项相加是可加的。

所以一维输入时模型取 $\hat{y} = \theta x + b$ 的形状。$\theta$ 称为权重，表示输入每增加一个单位时输出的变化量；$b$ 称为偏置，表示输入为零时的输出基准值。

偏置会破坏这两条性质：$b \neq 0$ 时输入取零而输出不为零，$f(ax) = a\theta x + b$ 也不等于 $a f(x)$。严格说来 $\hat{y}$ 只是仿射映射。模型名字里的“线性”指另一层含义：把特征固定、把参数 $(\theta, b)$ 当作变量，$\hat{y}$ 对参数满足齐次性与可加性。判据落在参数上，后面多项式回归之所以仍算线性，用的是同一个判据。

形式也没有多少可选的余地：有限维空间上满足这两条性质的映射一定能写成加权求和，也就是矩阵乘法。线性模型的形式由这两条性质确定，不是随手挑选的结果。

权重的含义由此确定：$\theta_j$ 是特征 $j$ 增加 1 个单位时预测值的变化量，其余特征保持不变，与其余特征的具体取值无关。线性模型里没有特征之间的交互作用：两个特征同时变化带来的影响，等于各自单独变化带来的影响之和。权重因此便于解释，但模型难以表达特征之间的复杂交互。

几何上，一维输入时这条关系落在一条直线上，两个特征时落在一个平面上，特征更多则落在比所在空间低一个维度的平坦子集上，这样的子集称为超平面。斜率、截距这些说法只在二维里便于指认，能带到高维的只有“加权求和再加偏置”这个结构。

# 从逐特征展开到向量内积

把 $d$ 个特征逐个写出来，模型是一串乘积之和：$\hat{y} = \theta_1 x_1 + \theta_2 x_2 + \cdots + \theta_d x_d + b$。样本是表格里的一行，特征的取值排在这行的各列上，$x_j$ 是第 $j$ 个特征的取值，$\theta_j$ 是对应的权重。

特征一多，这个式子就长到难以阅读，几行符号里看不出结构。把样本的各个特征取值排成列向量 $\boldsymbol{x} = (x_1, \dots, x_d)^{\top}$，权重排成同样长度的 $\boldsymbol{\theta} = (\theta_1, \dots, \theta_d)^{\top}$，整串加权和就成为两个向量的内积：

$$\hat{y} = \boldsymbol{\theta}^{\top}\boldsymbol{x} + b$$

内积做的仍是加权求和：对应位置相乘再把乘积相加，转置只是把列向量排成可以相乘的形式。

偏置还可以换个位置安放：给每个样本末尾补一个恒为 1 的分量，把 $b$ 当作这个常 1 特征的权重，$\hat{y}$ 就只剩一项内积。后面解方程时正是这样处理。

单个样本如此。$n$ 个样本时，把每个样本的特征向量按行排列，得到的矩阵称为设计矩阵，记作 $\mathbf{X} \in \mathbb{R}^{n \times d}$，第 $i$ 行是第 $i$ 个样本的 $\boldsymbol{x}_i^{\top}$；标签排成向量 $\boldsymbol{y} \in \mathbb{R}^{n}$。全部样本的预测一次算出：

$$\hat{\boldsymbol{y}} = \mathbf{X}\boldsymbol{\theta} + b\boldsymbol{1}$$

$\boldsymbol{1}$ 是全 1 向量，偏置按分量加到每个样本上。矩阵乘法与内积是同一件事，只是把 $n$ 次内积并成一次。

一个特征还是一百个特征，变的只是加法有几项。设计矩阵的列数随特征数变化，行数随样本数变化，模型的结构始终是加权求和再加偏置。特征只有一维时，内积退化成两个标量相乘，形式上仍是同一个式子。

# 损失函数

形式确定之后，剩下的未知量是参数。参数取一组值，模型就有一个输出；要判断这组参数的好坏，得把输出和标签放在一起比较。损失函数做这个比较：把预测值与真实值之间的差压缩成一个数，再把所有样本的差汇总，数越小，模型在这批数据上越贴合。贴合样本这件事称为拟合。

单个样本上的差是**残差**，定义为预测值减真实值，$r_i = \hat{y}_i - y_i$。残差有正有负，落在零的两侧。

## 均方误差的三步

均方误差（Mean Squared Error, MSE）把残差整理成一个损失，分三步：对每个样本算出残差；把每个残差平方；对所有样本取平均。三步合起来是一个式子：

$$L(\boldsymbol{\theta}, b) = \frac{1}{n}\sum_{i=1}^{n} r_i^{2} = \frac{1}{n}\boldsymbol{r}^{\top}\boldsymbol{r}$$

其中 $\boldsymbol{r} = \hat{\boldsymbol{y}} - \boldsymbol{y}$ 是把所有样本的残差排成一列得到的残差向量。

除以 $n$ 这一步看着只是取平均，实际决定了两批数据之间能否比较：若改成求和，样本多的一批损失天然更大，读到的差别就分不清来自模型好坏还是来自数据多少。

损失函数在训练里充当被最小化的目标，不必等于最终汇报用的评价指标：训练要的是一个能逐步降下去的量，报告要的是一个能与业务对齐、能横向比较的量。两者的分工见 [[Model-Evaluation]]。

## 为什么平方

直接用残差求和不行，一正一负会互相抵消：两个样本各自偏了一个单位，和却是零，看上去毫无误差。平方之后所有项非负，正值与负值不再互相掩盖，这是第一条理由。

第二条理由与优化有关：平方把大误差放得更大。两个样本的误差分别是 3 和 0.4，平方后成为 9 与 0.16，量级上的悬殊才显出来。上图的 8 个样本里，残差最大的是 40.4，最小的不到 0.5，平方之后一个是 1630，一个接近 0，两个点就这样把损失拉开三个数量级。总损失里大误差因此占的分量更重，参数更新因而更容易受到大残差样本的影响。

两条理由指向同一件事：损失要能区分“偏了”与“偏得很远”，并且对后一种情形施加更大的压力。

## 平方的代价

放大的动作不分对象：错标或异常的样本同样带着一条大残差，平方之后足以主导总损失，模型为了迁就这一个样本而牺牲其余样本。换成绝对值可以压住这一点，但绝对值在残差为零处不可导，求解析解与算梯度都要另作处理。

另一处不便在量纲：损失以标签单位的平方计，图上的 $1630$ 要开方才知道相当于偏了 40 万元。

# 参数怎么解出来

有了损失，参数的好坏就有了统一标准，剩下的事是在参数的取值空间里找让 $L$ 最小的一组。有两条路：解方程，或者迭代。

## 正规方程

$L$ 是参数的凸二次函数；设计矩阵列满秩时，最低点唯一。在最低点处，$L$ 对每个参数的偏导数都为零。把这组条件写成矩阵形式，就得到正规方程。偏置要先并进设计矩阵，末尾加一列全 1，参数向量相应多一个分量，下式里的设计矩阵与参数向量都按增广后的维度理解。方程是：

$$\mathbf{X}^{\top}\mathbf{X}\,\boldsymbol{\theta} = \mathbf{X}^{\top}\boldsymbol{y}$$

当 $\mathbf{X}^{\top}\mathbf{X}$ 可逆时，解出 $\boldsymbol{\theta}$ 得到唯一的解析解，即能用公式一次写出的答案：

$$\boldsymbol{\theta} = (\mathbf{X}^{\top}\mathbf{X})^{-1}\mathbf{X}^{\top}\boldsymbol{y}$$

好处是一次算完：不用给初值，不用设步长，也不用定停止条件。参数个数不多、样本量适中时，这条路的代价很小，算出的就是精确的最小值，没有收敛快慢的问题。

前提写在式子里：$\mathbf{X}^{\top}\mathbf{X}$ 必须可逆。样本数少于参数个数时，$\mathbf{X}^{\top}\mathbf{X}$ 直接奇异；两个特征高度相关（一个能由另一个近似算出）时，矩阵接近奇异，解会对数据的微小变动极其敏感，算出的权重失去意义。不可逆时，最小化问题有多个解，解析式不能直接给出唯一的参数向量，需要借助伪逆或加正则项。计算量还随特征数增长得很快，特征多到一定程度就难以求解。让解稳定下来的常见手段是加正则项，取舍见 [[Model-Evaluation]]。

## 迭代逼近

第二条路不求逆，从一组初值出发，每一轮用当前参数算出预测与损失，再沿使损失下降的方向更新参数，重复到损失不再明显下降为止。每个参数都有一个偏导数，表示只让这一个参数变化时损失的变化率，这些偏导数排成的向量称为梯度。

迭代法不依赖矩阵可逆：不用求逆，每轮只做矩阵与向量的乘法，特征很多、样本很多时依然可行；代价是不能一步到位，要迭代到收敛，也就是损失不再明显下降、参数基本不再移动，多轮之后才靠近最低点。结果依赖初值、学习率与停止条件的设定；步长不合适时，损失可能震荡甚至发散，因此“每轮都更接近最低点”并不成立。梯度怎么算、步长怎么定、参数怎么更新，见 [[Gradient-Descent]]。

> [!note] 两条路的最小化目标相同
> 两条路要最小化的都是同一个 $L$。$\mathbf{X}^{\top}\mathbf{X}$ 可逆时，解析解是唯一全局最优；梯度下降在合适步长与收敛条件下逼近同一最优，但不保证每一轮的损失都下降，也不保证有限步内达到同一个数值解。

## 训练的循环骨架

采用梯度下降时，训练落在同一个循环骨架里：输入数据，计算预测，计算损失，计算梯度，更新参数，然后回到计算预测那一步。前四步都在当前参数上求值；第五步一旦改动参数，下一轮的量就全部作废，需要重算。损失是否随每轮下降取决于步长与问题的性质。

# 从线性回归出发

线性部分只有加权求和这一种运算，因此可以作为基础组件复用在其他模型中。下面三处改动都建立在这一部分之上。

## 多项式回归

第一处改动落在输入端：把每个特征换成由该特征构成的幂次项。

直线能表达的趋势有限。房价随面积的增长先慢后快时，一条直线无论怎么摆都跟不上这种弯曲，模型的形式需要多一点弯曲能力。把面积的一次项扩充成 $x, x^{2}, \dots, x^{d}$，模型变成：

$$\hat{y} = \theta_1 x + \theta_2 x^{2} + \cdots + \theta_d x^{d} + b$$

$d = 1$ 时退化成普通的线性回归，$d = 2$ 时拟合出的是一条抛物线，阶数越高，曲线能弯出的形状越多。阶数由人选定，属于模型形式的设定，不进入求解过程；一旦定下，待求的仍是那 $d + 1$ 个参数。

式子里出现了 $x^{2}$、$x^{3}$ 这样的非线性项，却仍归在线性模型里，因为判据看的是参数而不是特征：把 $x, x^{2}, \dots, x^{d}$ 当成 $d$ 个新特征，$\hat{y}$ 对新特征仍是加权求和再加偏置，对参数 $(\theta_1, \dots, \theta_d, b)$ 满足齐次性与可加性。

> [!important] 判据落在参数上
> 换个角度看同一件事：在 $x, x^{2}, \dots, x^{d}$ 张成的新特征空间里，模型依旧是一个超平面，所谓曲线只是这个超平面映回原来那条数轴上的样子。设计矩阵因此只是多了几列，正规方程与梯度下降的写法都不用改。

代价也在设计矩阵上：这些新列由同一列 $x$ 的幂次得来，彼此高度相关，$\mathbf{X}^{\top}\mathbf{X}$ 更容易接近奇异，阶数不能任意增加。特征的构造与筛选属于 [[Data-Preprocessing]] 的范围。

## 逻辑回归

第二处改动落在线性输出之后：接上一个非线性函数，再据此判断类别，例如一封邮件是不是垃圾邮件。这个函数称为激活函数，把任意实数映射到区间 $(0, 1)$，输出于是可以读作概率：

$$P(y=1 \mid \boldsymbol{x}) = \sigma(\boldsymbol{\theta}^{\top}\boldsymbol{x} + b) = \frac{1}{1 + e^{-(\boldsymbol{\theta}^{\top}\boldsymbol{x} + b)}}$$

$\sigma$ 是这里的激活函数，取值随输入变化的轨迹是一条 S 形曲线，输出与输入之间因此不再保持线性关系。模型的主体仍是那条加权求和，任务从给出一个数变成给出一个数之后判类别，损失也随之换掉，细节见 [[Logistic-Regression]]。名字里还留着“回归”，原因也在这里：被判断的量仍由线性部分给出，只是最后被压进概率区间。

## 深度学习

第三处改动落在层数上。

深度学习的做法是把“线性变换加激活函数”这一组操作重复多次，前一组的结果作为后一组的输入，层层相接。夹在中间、既不接触原始输入也不直接给出输出的层称为隐藏层，每一层的线性变换带一组自身参数。堆叠带来的变化在特征的来源：人只提供原始输入，中间该用哪些特征由模型学出，这称为自动提取抽象特征。
