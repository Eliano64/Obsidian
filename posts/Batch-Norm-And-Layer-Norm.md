# 归一化要解决的问题

初始化只处理第 0 步：权重按合适尺度采样，第一次前向的激活落在可控范围。这种控制是期望意义上的，只在权重与输入独立、分布对称等前提下近似成立。

训练开始后，每层权重按梯度更新，下一层看到的输入分布随之前后移动，初始尺度不再成立。归一化在训练过程中反复把激活按某一维重新定标，让后续层看到的均值与方差保持在可控范围，尺度推导见 [[Weight-Initialization-And-Variance]]。

归一化的位置不固定在线性层之后：输入侧可以做输入归一化，残差结构里归一化的位置也会影响训练稳定性。本篇比较的两种归一化都放在线性层之后、激活之前，这是最常见的排布。

# 标准化与仿射变换

标准化指减去均值、再除以标准差。批归一化（Batch Normalization）简称 BatchNorm 或 BN。层归一化（Layer Normalization）简称 LayerNorm 或 LN。两者都在标准化之后接一次仿射变换，即逐维乘 $\gamma$ 再加 $\beta$。

设 $\mu$ 与 $\sigma^2$ 分别是本次计算使用的均值和方差：

$$
\hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}, \qquad y = \gamma\,\hat{x} + \beta
$$

$\epsilon$ 是极小的常数（如 $10^{-5}$），防止除零。设输入矩阵的形状为 $[B, D]$，$B$ 是 batch 内样本数，$D$ 是特征维。$\gamma$ 与 $\beta$ 是可学习参数，都是长度 $D$ 的向量。

归一化控制均值与方差，不保证不同输入的完整分布相同。标准化后的方差为 $\sigma^2/(\sigma^2+\epsilon)$，只有方差远大于 $\epsilon$ 时才近似为 1；可学习的 $\gamma$ 与 $\beta$ 又把均值与方差调回网络需要的取值，此时输出方差不再是 1。

两种归一化的区别，在于哪些元素一起参与均值与方差的计算。对 $[B, D]$ 矩阵，BN 固定一个特征，取所有样本在该特征上的取值算一组；LN 固定一个样本，取该样本的所有特征算一组。

# 常用归一化方法

## BatchNorm

BN 对每一列（每个特征）用 $B$ 个样本算一组均值与方差，共 $D$ 组：

$$
\mu_j = \frac{1}{B}\sum_{i=1}^{B} x_{ij}, \qquad \sigma_j^2 = \frac{1}{B}\sum_{i=1}^{B}\left(x_{ij} - \mu_j\right)^2
$$

其中 $\mu_j$ 是第 $j$ 个特征的均值，$\sigma_j^2$ 是该特征的方差。

$\gamma_j$ 与 $\beta_j$ 也按特征给出，形状为 $[D]$。

训练时用当前 batch 算出的均值与方差，同时用滑动平均维护一组 running 估计：

$$
\text{running} \leftarrow (1 - m)\,\text{running} + m\,\text{batch\_stat}
$$

PyTorch 的动量参数 $m$ 默认是 $0.1$，含义是新 batch 占 10%。

训练中的 running\_var 用 batch 的无偏方差更新，标准化本身用有偏方差。无偏方差分母为 $B-1$，有偏方差分母为 $B$，两者在 $B$ 较小时差别明显。running 估计是此前各 batch 的指数滑动平均，不等于全体训练数据的精确统计量。

推理时默认用 running 估计，不用当前 batch 的统计量。推理完全可以一次处理一批样本；采用 running 估计，是为了让每个样本的输出不依赖同批的其余样本。用当前 batch 统计会让同一个样本在不同批次里得到不同结果，评估与部署都无法接受。

把 `track_running_stats` 设为 `False` 时，BN 在推理时改用当前 batch 的统计量。这是保留的例外设置。

## LayerNorm

LN 对每一个样本，用该样本自身的特征算一组统计量：

$$
\mu_i = \frac{1}{D}\sum_{j=1}^{D} x_{ij}, \qquad \sigma_i^2 = \frac{1}{D}\sum_{j=1}^{D}\left(x_{ij} - \mu_i\right)^2
$$

$\gamma_j$ 与 $\beta_j$ 在样本之间共享，形状为 $[D]$。LN 不依赖 batch size，训练与推理用同一套计算，不需要 running 统计。

Transformer 可以把 LN 放在子层之前，这种排布称为 pre-LN。对形状为 $[B, T, D]$ 的序列输入（$T$ 为序列长度），LN 通常归一化最后一维 $D$，每个时间步各自统计一次。$T$ 可变不影响这套计算，其他位置上的 padding（补齐到相同长度而填入的占位值）不会影响某个真实时间步在 $D$ 维上的统计量。

需要在归一化中跨 $T$ 求统计量时（例如把整个序列当一个样本），padding 才会进入 $\mu$ 与 $\sigma^2$，这时必须按有效长度或掩码处理。掩码是用 0/1 标记有效位置，并在统计与损失中排除无效位置。注意力和损失仍需排除填充位置，LN 不会代为完成屏蔽。

# 数值例子

## 同一个矩阵上的两种结果

取 4 个样本、3 个特征的小矩阵：

| 样本 | 特征 1 | 特征 2 | 特征 3 |
| --- | --- | --- | --- |
| 1 | 1 | 5 | 2 |
| 2 | 4 | 7 | 3 |
| 3 | 2 | 6 | 9 |
| 4 | 8 | 9 | 4 |

BN 沿列统计。第一列均值 3.75、标准差 2.681，标准化后是 $-1.026$、$0.093$、$-0.653$、$1.585$。每一列都这样处理，得到的矩阵每列均值 0、方差 1（手算时忽略 $\epsilon$ 的量级）。

LN 沿行统计。第一行均值 2.667、标准差 1.700，标准化后是 $-0.981$、$1.373$、$-0.392$。四行各自零均值单位方差。

同一个格子是 7。BN 固定特征 2，用四个样本在特征 2 上的取值算均值与方差，得到 $0.169$；LN 固定样本 2，用该样本三个特征算均值与方差，得到 $1.373$。数值不同，因为参与计算的元素不同。

再看仿射参数。取 $\gamma_2 = 1.5$、$\beta_2 = -0.2$，对这个格子，BN 的输出是 $1.5 \times 0.169 - 0.2 = 0.054$，LN 的输出是 $1.5 \times 1.373 - 0.2 = 1.860$。

取 $\gamma = 1$、$\beta = 0$ 时输出等于标准化结果本身，即恢复到标准化后的尺度，不是恒等映射。

## 训练与推理的数值差别

以第二列的格子 7 为例。训练时这一列的 batch 均值是 6.75、标准差 1.479，标准化结果是 $0.169$。

推理时改用 running 估计。假定训练过程中积累的 running 均值是 6.9、running 方差是 2.4（这组数值是本例的给定输入，不是上面四个样本算出来的），则推理时的标准化结果为：

$$
\hat{x} = \frac{7 - 6.9}{\sqrt{2.4 + \epsilon}} \approx 0.065
$$

与训练时的 $0.169$ 不同，因为统计量的来源不同。

# 两种归一化的对比

| 项目 | BatchNorm | LayerNorm |
| --- | --- | --- |
| 均值和方差的计算范围 | 同一特征在各样本上的取值 | 同一样本各特征的取值 |
| 是否依赖 batch 组成 | 训练时依赖，推理用 running 估计 | 不依赖 |
| 训练与推理 | 默认不同 | 相同 |
| 可学习参数 | $\gamma_j$、$\beta_j$，形状 $[D]$ | $\gamma_j$、$\beta_j$，形状 $[D]$，样本间共享 |
| 典型场景 | 卷积网络、全连接网络，batch 较大 | Transformer、RNN、变长序列 |

换成 $[N, C, H, W]$ 的卷积输入：$N$ 是样本数，$C$ 是通道数，$H$ 与 $W$ 是特征图的高和宽。BN 对每个通道跨 $N$、$H$、$W$ 统计，统计量个数为 $C$；LN 需要指定归一化的维度集合，统计量个数随样本数增长。

> [!important] batch 为 1 时的两种形状
>
> 二维输入 $[B, D]$ 且 $B = 1$ 时，每个通道只有一个数值，方差为 0，PyTorch 在训练模式会直接报错（要求每个通道多于一个值，见 [BatchNorm1d 文档](https://pytorch.org/docs/stable/generated/torch.nn.BatchNorm1d.html)）。
>
> 卷积输入 $[N, C, H, W]$ 且 $N = 1$ 时，每个通道有 $H \times W$ 个数值。$H \times W > 1$ 时参与计算的元素个数大于 1，满足训练时的计算要求；元素个数大于 1 不保证方差非零，各元素可以相等。$H \times W = 1$ 时与二维情形相同，只剩一个数值。
>
> 因此，batch 大小为 1 时是否可用 BN，取决于每个通道有多少个数值参与统计。

# 归一化与尺度的关系

同一组参与计算的输入方差非零时，将组内所有数值变为 $x'=cx+d$，其中 $c>0$，$d$ 在组内为常数。忽略 $\epsilon$，组均值变为 $c\mu+d$，标准差变为 $c\sigma$，因此标准化结果不变。

$\gamma$ 与 $\beta$ 作用在标准化之后；固定这两个参数时，输出也不变。仿射参数不会被本层的标准化消除。

对前一仿射层 $x=Wa+b$，同时缩放 $W$ 与 $b$，可得到 $x'=cx$。只缩放 $W$ 时，$x'=cx+(1-c)b$。此时是否满足不变性，取决于偏置在参与计算的元素上是否为常数。

BN 训练时，逐通道偏置在各元素上相同，可以被减均值消除。LN 中逐特征偏置一般不同，不能作相同推断。BN 推理使用固定的 running 统计量，上述不变性也不自动成立。逐元素不同的缩放与负数缩放同样不在这条命题的范围内。

归一化能减轻部分尺度变化的影响，但不能替代初始化。输入侧、残差相加处、输出层等位置未被相应归一化覆盖，仍需控制初始化尺度。

# 机制证据与适用边界

BN 的一种解释是内部协变量偏移（internal covariate shift）：训练中前层参数变化，会使后层输入的分布移动（[Ioffe 与 Szegedy](https://arxiv.org/abs/1502.03167)）。

另有实验表明，这一偏移并不是归一化起作用的必要条件：即使人为注入偏移，BN 仍然有效，损失曲面的平滑程度与优化行为的变化更能解释观察到的收益（[Santurkar 等](https://arxiv.org/abs/1805.11604)）。两种解释的适用范围不同，前者描述现象，后者给出替代性证据。

LN 处理的是 batch 统计的依赖问题：batch 很小或长度可变时，沿 batch 统计不稳定，而按样本自身特征统计不受此影响（[Ba 等](https://arxiv.org/abs/1607.06450)）。
